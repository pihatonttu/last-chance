# Last Chance: Arctic – toteutussuunnitelma

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Saaripeli muuttuu napakyläksi: aina talvi, iglut, kasvihuoneet, jää, kiinteä nuotio
pakkasen mukaisella puuntarpeella, rantajää ja avannot, revontulijuhla, jäänmurtaja ja
häviö, kun kylä luovuttaa.

**Architecture:** Säännöt (`packages/rules`) saavat pakkasen (`weather.ts`), nuotion
puuntarpeen kuun vaihteessa, jään iglujen hintana, rantautumisruudun nuotiopaikaksi ja
häviön. Tehtävä 1 lukitsee kaikki yhteiset tyypit (säännöt, protokolla ja jälkipuinnin
tyypit) ja pitää koko repon kääntyvänä. Sen jälkeen botit ja simulaattori, jälkipuinti,
palvelin ja asiakas etenevät rinnakkain. Kuvat tehdään omana virtanaan Blenderissä, ja
Samu hyväksyy näytearkin ennen koko renderöintiä. Sisäiset tunnisteet pysyvät
(`stone` = jää, `field` = kasvihuone, `shelter` = iglu ja niin edelleen).

**Tech Stack:** pnpm-monorepo, Node 24, TypeScript 7, Vitest 5, Svelte 5, PixiJS 8, Blender 5.1
(headless), Python 3.13 + Pillow.

**Spec:** [`docs/10-arktinen.md`](../../10-arktinen.md) (Samu hyväksyi 2026-10-23). Pohja:
[`docs/09-uudisasukkaat.md`](../../09-uudisasukkaat.md) ja sen suunnitelma
[`2026-10-13-uudisasukkaat.md`](2026-10-13-uudisasukkaat.md), jonka tehtävät 1–11 ja 13 ovat
haarassa `uudisasukkaat`.
