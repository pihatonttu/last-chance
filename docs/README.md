# Dokumenttien kartta

Dokumentit on kirjoitettu pelin kehittyessä, joten kaikki eivät enää kuvaa nykyistä peliä. Jos
dokumentti ja koodi ovat ristiriidassa, koodi ja `packages/rules/src/params.ts` ratkaisevat. Korjaa
silloin myös dokumentti.
